# Meta Ad Performance Dashboard

An interactive, data-driven dashboard designed to track, analyze, and optimize advertising campaigns across Meta platforms (Facebook and Instagram). This dashboard provides marketing teams and stakeholders with actionable insights into audience demographics, ad format performance, and key ROI metrics.

## Key Features & Visualizations

* **High-Level KPI Cards:** Track fundamental marketing metrics at a glance, including total Impressions, Clicks, Shares, Comments, Purchases, and overall Engagements.
* **Performance Ratios:** Real-time calculation of critical conversion metrics like Click-Through Rate (CTR), Engagement Rate (ER), Conversion Rate (CR), and Purchase Rate.
* **Budget Tracking:** Monitors total budget spend (e.g., $2.5M) and Average Budget Per campaign metrics to ensure fiscal efficiency.
* **Audience Demographics:**
  * **By Gender:** Breakdown of reach and engagement between Male, Female, and All targeted audiences.
  * **By Age:** Detailed distribution chart identifying peak performance age cohorts.
  * **By Geography:** Interactive map visualizing regional impression concentrations across global markets.
* **Trend Analysis:**
  * **Weekly & Hourly Impression Trends:** Granular timeline analysis to identify peak engagement days and times.
  * **Analysis by Month:** Calendar-integrated scheduling view for historical comparison (e.g., June performance).
* **Ad Type Analysis:** A tabular performance matrix breaking down metrics (IMPR, CLKS, CTR, PR, ER, CR) across different creative formats like **Stories**, **Video**, **Carousel**, and **Static Images**.
* **Dynamic Slicers:** Right-side filter pane allowing real-time data drilling by Platform (Facebook/Instagram), Dynamic Measures, Campaign Name, and Target Interest.
